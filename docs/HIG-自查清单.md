- [ ] 层级：5秒后能说出主任务、主数值和下一步；记录观察结果。
- [ ] 点击区域：用 DevTools 或布局测量取所有可点击元素最小宽高；网页触控目标≥44 CSS px，司机端≥48dp；列出小于44的元素。
- [ ] 对比度：用对比度工具测正文与背景，最低值≥4.5:1；记录最小值和颜色对。
- [ ] 深色模式：切换浅色/深色并检查文本、边框、状态色、图表和焦点；记录未适配项。
- [ ] 一致性：跨端执行同一主流程，核对文案、位置、状态和关闭方式；记录差异。
- [ ] 留白与对齐：覆盖网格线检查默认16px间距、对齐和内容宽度；记录拥挤、截断或被装饰挤压的位置。
- [ ] 动态字号：浏览器/系统放大至200%，检查横向滚动、重叠、截断、焦点顺序和操作可达性；记录读数。
- [ ] 反馈与动效：触发主操作，确认即时反馈、错误文本、可撤销性和减少动效模式；记录反馈时间或状态。
- [ ] 控件复用：标出每个标准控件来源；若新造控件，写明标准控件为何不足及补齐的无障碍状态。
