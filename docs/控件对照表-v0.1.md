# 首批控件对照表 v0.1

| 控件 | Web | H5 | Native | 共同契约 |
|---|---|---|---|---|
| Button | `ZButton`（Ant Design） | `ZButton` | `ZButton` | children、disabled、loading、可访问名称 |
| Input | `ZInput`（Ant Design） | `ZInput`（原生 input） | `ZInput`（TextInput） | value、变更回调、禁用、可访问名称 |
| Select | `ZSelect`（Ant Design） | `ZSelect`（原生 select） | `ZSelect`（选项列表） | options、value、变更回调、可访问名称 |
| Switch | `ZSwitch`（Ant Design） | `ZSwitch`（role=switch） | `ZSwitch`（原生 Switch） | checked/value、变更回调、禁用、可访问名称 |
| Toast | `ZToast`（Alert） | `ZToast`（role=status） | `ZToast`（alert） | message、type、非阻断反馈 |

三端状态最少覆盖：默认、禁用、加载（Button）、键盘或系统无障碍名称。H5 控件的触控尺寸由消费方样式保证不小于 44px；Web 桌面点击区域不小于 32px。
